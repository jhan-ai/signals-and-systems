Convolution은 반전·이동·곱의 적분, 시작 시각과 신호 길이, 여러 임펄스에 대한 출력, 분할 합과 적분, 직렬·병렬 연결을 다룹니다. 푸리에는 sinusoids 합성, 주파수 성분 찾기, 푸리에 급수의 세 기본 실험을 제공합니다.

두 LAB 상단에 정의식·학습 목표·강의 연계를 표시합니다. 푸리에 계수는 DC를 a₀로 두는 강의 표기를 사용합니다. 강의 슬라이드의 크림색 배경(#fffddf), 회색 글자(#45505b), 붉은 강조색(#b93233)을 공통 디자인에 적용했습니다.

## Convolution 함수 직접 입력

기존 예제 옆의 **함수 직접 입력**에서 x(t), h(t)의 오른쪽 식을 입력하고 **함수 적용**을 누릅니다. `(t-1)u(t)`, `exp(-t)*u(t)`, `u(t-1)-u(t-3)`와 같은 표현을 지원합니다. 사칙연산, 거듭제곱, 괄호, 생략한 곱셈, `u`, `r`, `sin`, `cos`, `exp`, `abs`, `sqrt`, `log`/`ln`, `rect`, `sinc`, 상수 `pi`/`e`를 사용할 수 있습니다. 입력 가이드에서 각 함수의 정의를 확인할 수 있습니다.

- 예제 선택은 기존의 정확한 공식을 사용합니다.
- 직접 입력은 설정한 τ 구간의 **유한 구간 수치 적분**이며, 결과를 `y[a,b](t)`로 구별합니다. 출력 t 구간도 별도로 설정할 수 있습니다.
- 현재 t에서 적분 구간을 두 배로 넓힌 결과 및 계산 간격을 줄인 결과를 비교해 민감도를 안내합니다. 이는 무한 구간의 수렴 증명이 아닙니다.
- `(t-1)u(t)`와 `exp(-t)`의 무한 구간 convolution은 발산합니다. 인과적인 지수함수는 `exp(-t)*u(t)`로 직접 입력해야 하며 프로그램이 자동으로 u(t)를 추가하지 않습니다.
- 임펄스, 복소수, 특이점 적분은 지원하지 않습니다. 일반 수치 적분이므로 매우 빠른 진동이나 좁은 특성에 오차가 있을 수 있습니다.
- 수식은 제한된 문법으로 해석하며 JavaScript 실행, 속성 접근, 외부 스크립트를 사용하지 않습니다. 입력 내용은 서버에 저장하거나 전송하지 않습니다.
