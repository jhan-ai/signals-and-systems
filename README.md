Convolution은 반전·이동·곱의 적분, 시작 시각과 신호 길이, 여러 임펄스에 대한 출력, 분할 합과 적분, 직렬·병렬 연결을 다룹니다. 푸리에는 급수와 변환의 두 구역이 있으며, 각 구역에서 세 실험을 제공합니다. 이산시간 신호는 이번 확장에 포함하지 않습니다.

두 LAB 상단에 정의식·학습 목표·강의 연계를 표시합니다. 푸리에 계수는 DC를 a₀로 두는 강의 표기를 사용합니다. 강의 슬라이드의 크림색 배경(#fffddf), 회색 글자(#45505b), 붉은 강조색(#b93233)을 공통 디자인에 적용했습니다.

## Convolution 함수 직접 입력

기존 예제 옆의 **함수 직접 입력**에서 x(t), h(t)의 오른쪽 식을 입력하고 **함수 적용**을 누릅니다. `(t-1)u(t)`, `exp(-t)*u(t)`, `u(t-1)-u(t-3)`와 같은 표현을 지원합니다. 사칙연산, 거듭제곱, 괄호, 생략한 곱셈, `u`, `r`, `sin`, `cos`, `exp`, `abs`, `sqrt`, `log`/`ln`, `rect`, `sinc`, 상수 `pi`/`e`를 사용할 수 있습니다. 입력 가이드에서 각 함수의 정의를 확인할 수 있습니다.

- 예제 선택은 기존의 정확한 공식을 사용합니다.
- 직접 입력은 설정한 τ 구간의 **유한 구간 수치 적분**이며, 결과를 `y[a,b](t)`로 구별합니다. 출력 t 구간도 별도로 설정할 수 있습니다.
- 현재 t에서 적분 구간을 두 배로 넓힌 결과 및 계산 간격을 줄인 결과를 비교해 민감도를 안내합니다. 이는 무한 구간의 수렴 증명이 아닙니다.
- `(t-1)u(t)`와 `exp(-t)`의 무한 구간 convolution은 발산합니다. 인과적인 지수함수는 `exp(-t)*u(t)`로 직접 입력해야 하며 프로그램이 자동으로 u(t)를 추가하지 않습니다.
- 임펄스, 복소수, 특이점 적분은 지원하지 않습니다. 일반 수치 적분이므로 매우 빠른 진동이나 좁은 특성에 오차가 있을 수 있습니다.
- 수식은 제한된 문법으로 해석하며 JavaScript 실행, 속성 접근, 외부 스크립트를 사용하지 않습니다. 입력 내용은 서버에 저장하거나 전송하지 않습니다.

## 슬라이드와 연결된 푸리에 실험

1. **sinusoids 합성**: 기존 진폭·주파수·위상 조절과 예제를 유지합니다.
2. **주파수 성분 찾기** (145–148쪽): 성분별 내적이 `k≠m`에서 0, `k=m`에서 `XₘT`가 되는 과정을 표로 보여줍니다. 성분의 k를 선택하면 complex conjugate를 곱하고 지수함수 그대로 적분하는 풀이가 표시됩니다. 마지막에 T로 나누어 Xₘ을 구합니다. 기본 예시는 148쪽의 세 성분에 X₁=1, X₂=0.8, X₃=0.5, T=2를 넣은 복소 신호이며, 그래프에 Re/Im을 구분합니다. 154쪽의 신호와 01에서 만든 실수 신호도 분석할 수 있습니다. 주기 T를 바꾸면 신호의 기본 주파수도 바뀌며, 항상 한 주기에서 내적한다는 점을 표시합니다.
3. **푸리에 급수** (150·152–154쪽): 예제 5-5의 펄스에서 계수를 계산하고, 진폭·위상 스펙트럼과 유한 부분합을 연결합니다. 예제 5-3에서는 주어진 계수에서 삼각함수의 합으로, 154쪽 예시에서는 신호에서 계수와 합성으로 이어집니다. k=0은 별도로 적분하고, 선택한 k와 합성 차수 N을 구분합니다. 파스발 관계로 원래 신호의 평균 전력과 −N~N차 부분합의 평균 전력을 비교합니다. 0 신호에서는 전력 비율을 계산하지 않습니다.

급수 구역의 설명은 첨부 강의 슬라이드의 내적·직교성·지수함수형 급수·분석과 합성을 따릅니다. 기존 복소지수 쌍 탭, 내적의 면적/누적 적분 관찰, 별도 cos·sin 검출 모드, Gibbs 설명, 이전 사각파·삼각파·톱니파 예제는 급수 화면과 실행 코드에서 제거했습니다. 그래프는 SVG, 수식은 Native MathML입니다. 새로운 계산은 닫힌 형태의 연속시간 식을 사용합니다.

## 푸리에 변환 실험

상단의 **푸리에 변환**을 선택합니다. 각 화면으로 바로 이동할 수 있는 주소도 지원합니다.

1. **급수에서 변환으로** — `fourier/#transform-bridge`
   - 높이 1, 폭 2의 펄스를 고정하고 주기 T만 늘립니다.
   - 가로축은 실제 각주파수 ω이며, 계수의 간격은 ω₀=2π/T입니다.
   - 기본 비교는 `T Xₖ = X(kω₀)`입니다. 실제 계수 모드에서는 `Xₖ`와 `X(ω)/T`를 비교하여 정규화와 실제 계수를 구별합니다.
   - 기존 급수 실험의 T 조절은 폭의 비율 w/T를 유지하므로, 두 실험의 목적을 구별합니다.
2. **시간 이동과 압축** — `fourier/#transform-properties`
   - 사각 펄스, 삼각 펄스, 인과적 지수 신호에 `y(t)=A x(a(t−t₀))`, a>0을 적용합니다.
   - `Y(ω)=(A/a) X(ω/a)e^(−jωt₀)`에 따라 시간 파형, 크기와 위상 스펙트럼을 함께 표시합니다.
   - 스펙트럼이 0인 지점의 위상은 표시하지 않고, 위상 경계의 점프를 연결하지 않습니다.
   - 신호의 면적 Y(0) 및 에너지를 비교합니다. 시간 압축 자체가 에너지를 보존한다는 설명을 사용하지 않습니다.
3. **주파수 응답** — `fourier/#transform-response`
   - `h(t)=a e^(−at)u(t)`, `H(ω)=a/(a+jω)`를 사용합니다.
   - 두 정현파의 정상상태 응답에서 각 성분의 진폭과 위상 변화를 확인합니다.
   - 사각 펄스 입력에서는 과도응답을 포함한 정확한 출력을 보여주어 `y=x*h`와 `Y=HX`를 연결합니다.

현재 표시된 그래프는 SVG로 저장할 수 있습니다. 모든 실험은 브라우저에서 동작하며 입력을 서버에 저장하지 않습니다. 주파수의 단위는 변환 구역에서 ω (rad/s)입니다. 라플라스·z 변환과 이산시간 실험은 추가하지 않았습니다.

새 계산과 화면은 `fourier/transform-math.js`, `fourier/transform.js`, `fourier/transform.css`, 상위 구역 전환은 `fourier/sections.js`, `fourier/sections.css`에 있습니다. 기본 신호의 변환은 닫힌 형태의 식이며, 테스트에서는 독립적인 시간 영역 수치 적분과 비교합니다.
