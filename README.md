# 신호 및 시스템 · Signals & Systems

파라미터를 조절하고 SVG 파형을 비교하며 배우는 공개 교육용 사이트입니다. 학생 로그인, 데이터 전송, 외부 스크립트·폰트가 필요하지 않습니다.

공개 주소: https://jhan-ai.github.io/signals-and-systems/

## 강의 순서

LAB 번호는 제공된 159페이지 강의자료에서 주제가 처음 상세히 설명되는 순서를 따릅니다. 같은 주제의 후반 예제는 해당 LAB의 추가 탭에 모았습니다. `labs/catalog.json`에 PDF 페이지와 전체 목록을 기록했습니다.

| LAB | 실험실 | 경로 | 주요 내용 |
| --- | --- | --- | --- |
| 01 | 샘플링 | `sampling/` | 샘플링, 양자화, 앨리어싱·sinc 복원(심화) |
| 02 | 에너지·전력 | `energy/` | 관측 구간, RMS, 연속/이산 극한 |
| 03 | 주기와 대칭 | `symmetry/` | 유리/무리 주파수비, 이산 주기, 짝·홀 분해 |
| 04 | 시스템 성질 | `properties/` | 선형성, 시불변성, 인과성, 기억, BIBO 안정성 |
| 05 | 기본 신호 | `signals/` | 계단, 램프, 임펄스, 스위치, Sa/sinc, 기본 연산 |
| 06 | 오일러 공식 | `euler/` | 복소 벡터, 실수부·허수부, 성장·감쇠 |
| 07 | 신호 변환 | `transformations/` | 좌표 대응, 변환 순서, 강의 예제 |

| 09 | Convolution | `convolution/` | 기존 실험, 시작점, 임펄스 응답 합, Δτ, 연결 |
| 10 | 푸리에 | `fourier/` | 기존 합성·분석·급수, 지연, 기본 주기, Dirichlet |

기존 `convolution/`과 `fourier/` 주소 및 기본 기능을 유지합니다. 강의 본문 밖의 내용은 후속 학습 또는 심화로 표시합니다.

## 실행·게시

일반 정적 HTML/CSS/JS입니다. 별도 빌드 없이 열 수 있으며 개발 시 `python -m http.server 8000`으로 확인할 수 있습니다. GitHub Pages는 `main` 브랜치 루트(`/`)를 게시합니다. `.nojekyll`을 유지하세요. npm은 개발 검증에만 사용합니다.

- `labs/math.js`: 순수 계산 함수
- `labs/ui.js`: 반응형 SVG, 탭, 슬라이더, 키보드 조작, 재생
- `labs/experiments.js`: 실험별 파라미터, 예제, 그래프, 설명
- `labs/style.css`: 공통 화면
- `fourier/`, `convolution/`: 기존 계산·화면과 추가 실험 영역

## 계산상의 주요 구분

- 수치 실험 한 번으로 보편적인 선형성·시불변성·주기성·안정성을 증명하지 않습니다. 이론 판정과 관찰을 구별합니다.
- 영입력은 외부 입력이 0, 영상태는 초기조건이 0입니다. Convolution은 영상태 응답입니다.
- ODE 초기조건은 0⁺ 값입니다. 특성근 λ의 시간 항은 e^(λt)입니다.
- 단측 코사인 진폭·위상 스펙트럼을 사용합니다. 같은 주파수는 복소 진폭으로 합하고, 0 진폭의 위상은 정의하지 않습니다.
- 같은 시간 지연은 주파수마다 −2πft₀만큼 다른 위상 변화를 만듭니다.
- 임펄스의 화살표는 가중치(면적)입니다. 유한 폭 근사는 폭과 높이를 구별합니다.
- Dirichlet 조건은 충분조건입니다. 절대적분 하나만으로 세 조건을 모두 확인한 것은 아닙니다.
- 정현파 필터 출력은 정상상태, sinc 복원은 유한 샘플 근사, 변환 적분·급수의 유한 합은 무한 변환과 구별합니다.
