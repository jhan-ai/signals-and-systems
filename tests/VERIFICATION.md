# 신호 및 시스템 실험실 검증

## 수치 검증

실행: `node tests/math.test.cjs`

- 7,383개 수치 assertion 통과.
- Fourier: 강의 예제, 동일 주파수의 합성과 상쇄, DC, 위상 경계, 스펙트럼으로부터 신호 복원, cos/sin 투영, 사각파·삼각파·톱니파 급수.
- 120개 신호 조합에서 스펙트럼으로 복원한 파형의 최대 절대 오차: 약 2.02e-14.
- Convolution: 같은 폭·다른 폭의 사각 펄스, 펄스와 지수 감쇠, 같은/매우 가까운 지수 감쇠율, 음수 및 0 진폭, 인과성, 교환법칙.
- 100개 파라미터 조합에서 해석적 convolution과 별도로 계산한 중점 수치 적분의 최대 절대 오차: 약 2.77e-8.

## 조작 이벤트 검증

jsdom 기반으로 세 페이지의 로딩 및 조작 이벤트를 모의 실행했습니다. 759개 DOM assertion을 통과했고, 처리되지 않은 오류는 0건이었습니다.

확인한 기능: 실험실 링크, SVG 경로의 유한값, Fourier 예제 선택·슬라이더·탭·자동 탐색·성분 켜기/끄기·급수 차수, convolution 예제·슬라이더·신호 교환·자동 재생/일시정지·뒤집기 참고선, 잘못된 도구 입력 시 상태 유지.

## 수정 사항

- 수학적으로 같은 π와 −π가 스펙트럼과 분석 화면에서 서로 다르게 표시되던 경계를 π로 통일.
- 톱니파의 정수 주기 경계에서 부동소수점 오차에 대한 처리를 보강.
- 진폭이 0일 때 위상 안내 문구를 두 줄로 표시.
- 성분 켜기/끄기 후 키보드 초점을 유지.
- 성분이 없는 경우에도 나타날 수 있던 ‘찾은 주파수’ 레이블을 ‘선택한 주파수’로 변경.

## 검증 범위

실제 브라우저에서의 시각적 배치·모바일 화면·터치 조작 검증은 수행하지 않았습니다. jsdom은 렌더링 엔진이 아니므로 이 문서의 DOM 검증은 실제 브라우저 검증을 대체하지 않습니다. 실제 WebMCP 지원 브라우저에서의 등록 검증도 수행하지 않았습니다.
