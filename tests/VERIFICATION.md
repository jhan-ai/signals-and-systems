검증일: 2026-10-05. 정적 배포이며 서버 계산, 학생 계정, 외부 런타임 라이브러리를 사용하지 않습니다.

## 수학 검증

`node tests/math.test.cjs` — 기존 7,383개 assertion 통과.

- 동일 주파수 복소 합성·상쇄, DC, ±π 경계, 위상 미정, cos/sin 투영, 3종 푸리에 급수.
- 120개 입력 조합의 스펙트럼 재구성 최대 절대 오차: 2.02×10⁻¹⁴.
- 기존 사각/지수 Convolution: 인과성, 부호, 교환법칙, 같은/거의 같은 감쇠율.
- 해석식과 독립적인 중점 적분의 최대 차이: 2.77×10⁻⁸.

`node tests/extensions.test.cjs` — 새 1,021개 assertion 통과.

- 연속시간 유한 구간 에너지와 분할 수치 적분 비교.
- 강의 1차/2차 계 예제와 초기조건, 서로 다른 근·중근·중근 인접값.
- 독립 RK4 해와 닫힌 해 비교: 최대 차이 2.38×10⁻¹⁰ 미만.
- 이동된 사각 펄스의 지지구간 끝점과 교환법칙.
- 삼각 입력과 지수 응답의 해석적 Convolution: 독립 적분과 최대 차이 9.88×10⁻⁹ 미만.
- Δτ 감소에 따른 지정 사례의 근사 개선, 가중 임펄스 합, 피해율 40과 누적량 60의 구분.
- 3개 직렬·병렬 경로와 등가 임펄스 응답.
- 코사인 샘플의 앨리어싱 항등식, sinc 영점, 비양자화 시간 지연 위상, 필터 차단점, 피드백의 원점 극점, 시간 변환의 표시점.

이 검사들은 구현 회귀를 찾기 위한 대표 사례·독립 수치 비교이며 모든 가능한 입력에 대한 수학적 증명을 대신하지 않습니다.

## 화면 요소·조작 이벤트 검증

jsdom 30.1.2 / Node 24 환경에서 전체 페이지를 실제 HTML과 연결된 스크립트로 로드했습니다.

- 홈페이지 13개 LAB 링크와 강의 순서.
- 31개 추가 실험 탭, 318개 상태·조작 시나리오, 2,790개 assertion.
- 모든 선택 예제, 슬라이더 양 끝값, 초기화, 키보드 탭 이동, 재생/정지 상태.
- SVG의 유한 좌표, 중복 ID, 입력 레이블, 기존 Convolution 시간 조절·교환과 푸리에 기존 탭.
- 상단 푸리에 신호가 바뀌면 시간 지연 확장 실험도 같은 입력을 즉시 읽는 연결.
- 처리되지 않은 스크립트 오류 0건.
- 14개 HTML 페이지의 상대 링크·스크립트·스타일 경로 존재 확인.

## 모델의 범위와 설명 수정

- 관측 구간의 적분·RMS와 무한 구간의 에너지·평균 전력을 구분합니다.
- 정현파 샘플링의 sinc 복원은 유한 샘플 합이며, 원 신호의 정확한 복원 조건과 잔여 오차를 표시합니다.
- 시작 적분기는 t≥0에서 ∫₀ᵗx, t<0에서 0인 모델입니다. 인과적이지만 고정 시작 시각 때문에 시변입니다.
- ODE 초기조건은 0⁺ 값입니다. 입력 미분에 따른 원점 임펄스와 그 이후 방정식을 구별합니다.
- 영입력/영상태 분해를 과도/정상상태 분해와 동일시하지 않습니다.
- λ가 특성근일 때 e^(λt)를 사용하며 중근의 t 항을 포함합니다.
- Dirichlet은 충분조건이며, 한 조건이나 짧은 화면 관찰만으로 전체 성질을 판정하지 않습니다.
- 변환의 대수적 식과 ROC 안에서 정의되는 무한 적분·급수를 구별합니다.

## 남은 검증 범위

현재 세션에서 브라우저 관찰 API가 “native credentials가 포함된 문서의 관찰 불가” 오류를 반환하여 실제 렌더링 화면 캡처를 확인하지 못했습니다. jsdom은 레이아웃 엔진이 아니므로 실제 모바일 기기, 터치 드래그, 브라우저별 배치, 애니메이션 프레임 성능은 검증되지 않았습니다. 반응형 CSS와 SVG 좌표를 구현했지만 실제 기기 검증으로 간주하지 않습니다.

기존 WebMCP 등록은 기능 감지로 유지합니다. 실제 지원 브라우저에서 도구 등록을 이번 변경으로 검증하지는 않았습니다.
